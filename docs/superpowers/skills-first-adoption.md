## Project binding and policy departures

The starter helper's configure preview refused legacy .agents/skills/gzs-git-sync.
Its hardcoded origin also names `tvproductions/skills-first-starter.git`, rather
than the requested `tvproductions/gz-skills-first-starter.git`. Adoption therefore
uses project-owned configuration and the corrected provenance URL, preserving
the upstream checkout. This is an explicitly adapted binding, not an unchanged
helper application or a new starter release.

The project catalog in .agents/plugins/marketplace.json is named
`xplane-webapi-skills-first`; its component SHAs match the reviewed starter.
The native manager registers this checkout's local catalog. .codex/config.toml
enables only the project's selected pair and disables other known discovery
sources for those components in this project. Native installation added global
enablement entries; only the new pair's entries were set to false afterward.
Existing installations and other projects' selections were preserved.

AGENTS.skills-first.md owns project routing and these engineering departures:

- Python 3.12 only, selected explicitly for XPPython adjacency; no automatic 3.14
  migration or claim of embedded host validation.
- Existing full quality checks, thresholds and pre-commit/CI enforcement remain
  authoritative instead of adopting the starter's on-demand-only deep checks.
- uv owns runtimes, environments, dependency changes and execution. Routine
  commands use the frozen lock; Twine is now a locked development dependency.
- Existing application dependencies and operational skills remain project-owned.
  Generic engineering maintenance composes gz-skills with project quality commands.

The uv lock was regenerated by uv for the narrowed runtime range and Twine's
development dependencies. Existing runtime dependencies were retained. CI and
release archive validation now require 3.12; metadata and classifiers no longer
claim 3.13 support. This changes future distributions; already published packages
retain their original metadata.
